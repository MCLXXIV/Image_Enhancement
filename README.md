## Оценка сложности

### Потенциал проекта

Проблема плохого качества фотографий важна, потому что фото напрямую влияет на восприятие объявления пользователем. Если изображение тёмное, размытое, пересвеченное или с низким контрастом, товар хуже считывается визуально: пользователю сложнее понять состояние объекта, заметить детали и принять решение о покупке.

При помощи применения эвристик выяснено, что 38 831 из 100 000 нуждаются в улучшении качества. По нашим предположениям улучше ние фото будет приводить к увелечению покупок на авито, также проект будет полезен для внутренних моделей, например, модерации (моделям модерации будет проще найти нарушения на фото).


### Ограничения

Сервис должен работать с >= 1rps. 

### Решение без МО

Для поиска плохих изображений можно использовать классические метрики обработки изображений:

- средняя яркость
- доля слишком тёмных пикселей
- доля пересвеченных пикселей
- контраст
- резкость через дисперсию лапласиана
- энтропия изображения

Для улучшения можно использовать простые методы:

- gamma correction для осветления тёмных фотографий
- CLAHE для повышения локального контраста
- white balance / gray world correction для коррекции цвета
- unsharp mask для повышения резкости
- denoising-фильтры для уменьшения шума


Минус такого подхода в том, что он работает по фиксированным правилам. На части изображений методы могут ухудшить качество: пересветить фото, усилить шум, сделать цвета неестественными или не помочь в сложных случаях. Кроме того, параметры придётся вручную подбирать под разные типы фото и категории товаров.

### Решение с применением МО

Найденные модели, которые можно использовать как основу для решения:

- [Zero-DCE](https://github.com/Li-Chongyi/Zero-DCE) - модель для автоматического осветления тёмных изображений. 

- [EnlightenGAN](https://github.com/VITA-Group/EnlightenGAN) - модель для улучшения тёмных фотографий.

- [MIRNet](https://keras.io/examples/vision/mirnet/) - модель для восстановления и улучшения качества изображений. Используется для задач: уменьшение шума, повышение детализации.


## План решения

В рамках проекта предлагается разработать сервис автоматического поиска и улучшения фотографий плохого качества.

Пользователь загружает фотографии товара при создании объявления. Для каждой фотографии сервис сначала оценивает качество изображения: яркость, контраст, резкость, наличие слишком тёмных или пересвеченных областей. Если изображение хорошего качества, оно остаётся без изменений. Если фотография определяется как некачественная, к ней применяется один из методов улучшения: осветление, повышение контраста, коррекция цвета, повышение резкости или ML-модель для восстановления качества изображения.

После обработки сервис сравнивает исходную и улучшенную версии. Если результат стал лучше и при этом изображение не было испорчено, улучшенная фотография используется в объявлении или предлагается пользователю как более качественный вариант.

### Бизнес метрики

Основная бизнес-цель проекта - повысить эффективность объявлений за счёт улучшения качества фотографий. Плохие фотографии могут снижать интерес покупателей, потому что товар хуже виден, сложнее оценить его состояние и детали. Если автоматически улучшать такие изображения, объявления должны становиться более понятными и привлекательными.

В качестве основной бизнес-метрики можно использовать конверсию из просмотра объявления в целевое действие:

- написание продавцу
- звонок продавцу
- добавление объявления в избранное
- покупка

Основная метрика:

`conversion_to_contact = количество целевых действий / количество просмотров объявления`

#### Метрики МО

- `brightness_mean` - средняя яркость изображения.
- `brightness_median` - медианная яркость изображения.
- `contrast_std` - контраст изображения: насколько сильно отличаются темные и светлые области.
- `entropy` - информативность изображения: насколько разнообразно распределены яркости и детали.
- `sharpness_laplacian_var` - резкость изображения: насколько выражены контуры и мелкие детали.
- `saturation_mean` - средняя насыщенность цветов.
- `colorfulness` - общая цветность изображения: насколько картинка выглядит цветной, а не серой или блеклой.
- `underexposed_ratio` - доля слишком темных пикселей.
- `overexposed_ratio` - доля слишком светлых, пересвеченных пикселей.
- `exposure_abs_error_to_0_6` - насколько средняя яркость отличается от целевого комфортного уровня яркости 0.6.
- `psnr_vs_input` - похожесть результата на исходное изображение по пикселям. Чем выше, тем меньше модель изменила картинку.
- `ssim_vs_input` - похожесть структуры результата на исходное изображение. Чем выше, тем лучше сохранены формы, контуры и детали.
- `lpips_vs_input` - визуальное отличие результата от исходного изображения по нейросетевой метрике. Чем выше, тем сильнее результат отличается глазами.
- `inference_sec` - время обработки одного изображения моделью.


#### Метрики сравнения с эталоном

- `PSNR` - показывает, насколько результат похож на эталон по пикселям. Чем выше `PSNR`, тем меньше пиксельная ошибка между картинками.
- `SSIM` - показывает, насколько результат похож на эталон по структуре: формы, контуры, текстуры, локальный контраст и общая структура объектов.
- `LPIPS` - показывает, насколько результат визуально отличается от эталона. Чем ниже `LPIPS`, тем визуально ближе результат к эталону.
